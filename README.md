# DataDetective AI – Conversational Data Analyst

## Overview

DataDetective AI is an AI-powered conversational data analysis application that allows users to upload datasets, ask questions in natural language, and explore data through SQL-backed analysis and interactive visualizations.

## Planned Features

- CSV and Excel dataset uploads
- Dataset preview and structural analysis
- Natural-language-to-SQL generation
- SQL validation and secure query execution
- Interactive data visualizations
- AI-generated explanations and business insights

## Technology Stack

- **Frontend:** React.js, Vite
- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **Data Processing:** Pandas, NumPy, OpenPyXL
- **Database Integration:** SQLAlchemy
- **SQL Validation:** SQLGlot
- **AI Integration:** OpenAI or Gemini API
- **Visualization:** Recharts

Currently in the initial development and environment setup phase.

Features will be updated as they are implemented and tested.
